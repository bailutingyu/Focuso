Focuso聚录

macOS 上的录屏 + 出镜摄像头 + 自动剪辑一体工具

录制时屏幕与摄像头分两层独立录制，录完自动进入剪映式编辑器，按你的鼠标点击自动放大画面 —— Screen Studio 式的精致效果，纯原生实现。

为什么用 Focuso

录屏、出镜、剪辑，一个工具全搞定

🎬

双图层录制

屏幕与摄像头分两层独立录制、互不干扰，后期可任意调整摄像头。

✨

点击自动放大

录完自动识别鼠标点击，生成平滑的「点哪放哪」缩放动效。

✂️

剪映式编辑器

时间线上增删/拖动缩放段、调倍数与焦点、首尾裁剪，所见即所得。

📐

固定比例 / 多屏

16:9 / 9:16 / 4:3 / 3:4 任选，可框选区域、指定任意显示器。

📷

摄像头随心摆

预览里直接拖动定位、缩放，圆形/圆角矩形、白边、调色。

🖼

壁纸背景

一键给画面加渐变壁纸 + 圆角，5 种预设或自选图片。

四步出片

从录制到成片，零学习成本

录制

选比例与显示器，开始录屏；摄像头浮窗常驻出镜。

自动放大

录完自动按点击生成缩放段，进入编辑器。

微调

拖动缩放段、摆摄像头、加壁纸背景、裁剪首尾。

导出

一键导出 HEVC 成片，所见即所得。

硬核而克制

🦅 纯原生，零依赖

  • 纯 Swift + AppKit，swiftc 一条脚本就能编
  • ScreenCaptureKit 录屏、AVFoundation 录摄像头/音频
  • 自定义 AVVideoCompositing 双图层合成，预览与导出共用一套
  • 常驻菜单栏，可「关闭摄像头」省电

🌐 还有网页版

  • 仓库附带纯网页版 focuso-web.html
  • 浏览器内「演示 + 出镜 + 提词 + 录制」
  • 基于 getDisplayMedia + MediaRecorder，无需安装
  • 用 Chrome / Edge 直接打开即用
